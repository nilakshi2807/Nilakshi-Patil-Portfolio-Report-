# Nilakshi Patil — Frontend Developer Portfolio

A sleek, responsive, and high-performance portfolio website built with **React 19**, **Vite**, and **Tailwind CSS**.

> **"Curious mind, creative vision, limitless possibilities."**

---

## 🚀 Quick Start

To run the portfolio on your computer:

```bash
# Start development server
npm run dev
```

Then open `http://localhost:5173` in your browser.

To create an optimized production build:

```bash
npm run build
```

## 🛠️ Personalizing Your Information

All your personal details, skills, projects, and contact info are centralized in a single file:

📁 **[`src/data/portfolioData.js`](file:///c:/Users/Student/Documents/portfolio%20workshop/src/data/portfolioData.js)**

### What you can customize anytime:
1. **Personal Information**: Name, title, tagline, bio, availability status, location, email, and social profile links (GitHub, LinkedIn, Twitter).
2. **Resume Link**: Place your PDF file in the `public/` directory (e.g. `public/resume.pdf`) and set `resumeUrl: "/resume.pdf"` in `portfolioData.js`.
3. **Frontend Skills**: Add or modify categories (Frontend Frameworks, State Management, UI/UX & Responsive Design, Tooling).
4. **Featured Projects**: Update titles, descriptions, live demo links, GitHub links, tech tags, and screenshots.
5. **Experience & Education**: Update your work history, company names, degrees, and dates.
